   Recommended: **dry** for Reddit, **dry** for Discord, **flat** for TikTok.
2. **The X composer refactor** (build-prompt §17): PR-1 moves the live X composer
   onto the shared loop. Recommended, with byte-equivalence proven on real past
   events before merge — but it is a risk the founder accepts explicitly.

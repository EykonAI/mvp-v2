# TikTok craft codex — DRAFT (becomes lib/copy/channels/tiktok/codex.ts in PR-2c)

CODEX_VERSION 2026-08-27.0 · owner: tiktok-copywriter subagent · refresh quarterly, next due 2026-11-27.
The artifact is a SCRIPT PACKAGE a human records — hook, beats+shots, voiceover, sound, caption, hashtags, limitBeat, lockup.

| id | rule | verified | enforcement |
|---|---|---|---|
| recordable-in-one-take | Every shot is a screen recording of a real eYKON view or a plain talking head. No B-roll, no stock, no chart that does not exist in the product. | true — house rule | hard |
| hook-first | No greeting, no introduction, no context-setting; the first line is the observation. (Reported: the first 2 seconds decide most retention.) | true as OUR structural rule; the retention figure secondary | hard on structure, warn on length |
| no-clickable-link | No URL in the caption as CTA. The CTA is the spoken/on-screen path eykon.ai/start/tiktok — survives privacy browsers by construction. | true — house rule, composes with path attribution | hard |
| caption-budget | Caption ≤ 2,200 chars, primary phrase inside the first ~150. (Conflict recorded: one skill reference says 4,000 — resolve against TikTok's own docs before hard-gating the higher figure.) | true as OUR budget | hard |
| hashtags-max-5 | ≤5 hashtags; 3–5 the working range. | true as OUR budget; limit reported since Aug 2025 | hard |
| lockup-and-end-card | Every script names the lower-third lockup (wordmark, feed, observation UTC, provenance state) and an end card carrying the path CTA. A script with beats but no frame furniture is not recordable as specified. | true — the §11.2 furniture invariant on the one channel where the asset is the video | hard |
| subtitles-burned-in | Every spoken line has a burned-in subtitle; most viewing is muted. Two lines max on screen, 3–5 words per line. | true as OUR rule; density figures secondary | hard on presence, warn on density |
| sound-policy | Spoken voiceover by default. A trending sound is permitted only where it does not shape the meaning; forbidden outright under the harm register. | true — house rule | hard under harm, warn otherwise |
| onscreen-text-density | ≤2 lines at once, 3–5 words per line. | false — secondary craft guidance | warn |
| length-band | Target 21–34 s; 15–30 s completes best. | false — secondary | warn |
| keyword-in-four-places | Primary phrase in voiceover, overlay, caption, hashtags. | false — secondary SEO guidance | guidance |
| state-the-limit | A dedicated beat for what the observation does not establish. | true — house rule | hard |
| no-shaping-under-harm | Harm register forced: no trending sound, no shaped hook, no withheld reveal, no countdown, no question. State and stop. | true — house rule, strictest form of the shared harm rule | hard |
| no-inbound-formats | Duets, stitches and reply-videos are out of scope: they are inbound-reactive, and this writer is write-only by the same boundary as Discord. | true — house rule | hard (structural) |
| name-a-source | Instrument named ON SCREEN, not only spoken. | true — voice codes | warn |
| cadence-mismatch | TikTok's ranking assumes near-daily posting; the SOP supplies 4–8 events/quarter. A runbook fact, not a lint — the founder decides whether the account exists at all. | false — secondary | guidance |

Register default (recommended): **flat** — the format supplies the energy. Harm
register: shared, absolute. Anti-tell: shared list, WARN.
